# Replication pack

Seeing Inequality Through Segregated Eyes: Network Segregation, Misperceived
Wage Differentials, and Attitudes Toward Redistribution

Everything needed to reproduce the paper's results, except the licensed
survey microdata itself (see `raw/README.md`).

## Contents

```
scripts/    01-08, run in numeric order (see "Pipeline" below)
data/       simulation output and ISSP-derived aggregate/model-level data
            (no respondent-level survey data -- see raw/README.md)
results/    every figure the paper cites, as produced by this code
raw/        not included (licensed data); raw/README.md explains how to
            obtain it
logs/       console output captured from the original run of each script
session_info.txt   R version and package versions used to produce the
            results here
```

## How to reproduce

Requirements: R (developed under R 4.6.0; see `session_info.txt`) and the
packages listed there. The simulation scripts (`01`, `04`, `05`) use
`statnet`/`ergm`/`igraph`; the empirical script (`07`) uses
`haven`/`sandwich`/`lmtest`/`clubSandwich`/`boot`.

```bash
cd replication_pack        # working directory must be this folder
for f in scripts/*.R; do Rscript "$f"; done
```

Or run scripts individually, in numeric order — every script's inputs are
already present in `data/` (regenerated by earlier-numbered scripts, or, for
`07`, requiring the raw ISSP file you supply yourself), so you can also run
any single script standalone against the data already checked in here.
All paths inside the scripts are relative to this folder; the working
directory must be `replication_pack/` itself when you invoke `Rscript`.

**A note on exact reproducibility.** `07_empirical_main.R` is single-threaded
and fully deterministic (fixed seeds throughout, including the cluster
bootstrap) -- re-running it reproduces every number in Tables 1–2 and S1
exactly. The simulation scripts (`01`, `04`, `05`, `09`) parallelize across cores
with `parallel::mclapply`; R's fork-based parallel RNG is not guaranteed
bit-identical run-to-run or across machines with different core counts, even
with a fixed seed. Re-running them reproduces the same qualitative pattern
and very close (third-decimal-place) numbers, not necessarily the exact
values checked into `data/` and `results/` here, which are the numbers
actually reported in the paper. `02_omega_extension.R` is a closed-form
post-processing step on `01`'s saved per-agent output and *is* bit-identical
on re-run (verified).
